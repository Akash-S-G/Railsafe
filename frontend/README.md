# Frontend — React + Vite + Tailwind + Leaflet + Recharts

```bash
cd frontend
npm install
npm run dev  # http://localhost:5173
```

Pages (see docs/architecture/dashboard.md): Overview → Map (risk-colored pins) → Inspection Upload → Detection Results → Component Inventory → Asset History → Risk Ranking → Maintenance Queue.

Backend: `http://localhost:8000` (FastAPI).
